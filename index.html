02 / The patch cord: try the rule yourself

The cord is startpage_redirection.js, my Tampermonkey userscript at version 0.2, with @grant none and @run-at document-start. On a DuckDuckGo page it reads the q parameter. If a query is present, it sends the browser to the StartPage address below. If there is no query, it does nothing.

https://www.startpage.com/do/search?q=hello%20world

My rule, stated without the box: take the constant https://www.startpage.com/do/search?q= and add encodeURIComponent(query). An empty box means no query, so my script leaves the page alone and produces no new address. This box is a demonstration on this page only. It does not redirect you anywhere.

04 / The whole cord, on the board

Here is all of startpage_redirection.js, 39 lines including its userscript header and my comments, with line numbers as they sit in the file.

 1  // ==UserScript==
 2  // @name         DuckDuckGo to StartPage Redirect
 3  // @namespace    http://tampermonkey.net/
 4  // @version      0.2
 5  // @description  Redirect DuckDuckGo search queries to StartPage
 6  // @match        *://duckduckgo.com/*
 7  // @match        *://*.duckduckgo.com/*
 8  // @grant        none
 9  // @run-at       document-start
10  // ==/UserScript==
11  
12  // I list two @match patterns because neither one covers the other:
13  // the first reaches the bare duckduckgo.com host on its own, and the
14  // second reaches the subdomains I actually land on, such as www and
15  // html. I ask for no Tampermonkey grants because I only read the
16  // address bar and assign a new one, which a page script can already
17  // do on its own.
18  (function() {
19      'use strict';
20      // I run this at document-start on purpose, and that choice is
21      // load-bearing: I need the redirect to fire before DuckDuckGo
22      // renders its own page, or I see the search engine I asked not
23      // to use and the browser does the work twice. Nothing I do here
24      // needs the DOM to exist first.
25      const searchURL = 'https://www.startpage.com/do/search?q=';
26      const params = new URLSearchParams(window.location.search);
27      const query = params.get('q');
28      if (query) {
29          // I encode the query again on the way out because
30          // URLSearchParams hands me the decoded text ("hello world"
31          // for ?q=hello+world). If I skipped encodeURIComponent, a
32          // query containing & or # would break out of my q parameter
33          // and change what the StartPage URL means.
34          window.location.href = searchURL + encodeURIComponent(query);
35      }
36      // If there is no query, I leave the page alone. That same check
37      // keeps me out of a loop: StartPage is on neither @match pattern,
38      // and a bare DuckDuckGo visit gives me no q to act on.
39  })();

I install it by adding a new userscript in Tampermonkey and pasting in this file. I ask for no grants because the script only reads the address bar and assigns a new one.

05 / Two match patterns, and why both stay

These two lines are copied from the header of the file, lines 6 and 7:

 6  // @match        *://duckduckgo.com/*
 7  // @match        *://*.duckduckgo.com/*

The first pattern, *://duckduckgo.com/*, covers the bare host only: duckduckgo.com itself, with no subdomain in front of it.

The second pattern, *://*.duckduckgo.com/*, covers subdomains, such as www.duckduckgo.com and html.duckduckgo.com, which is where DuckDuckGo is commonly used.

I added the second because the first alone missed those subdomains. StartPage appears in neither pattern, so a page my script sends you to cannot match and loop back.

07 / What I did not test, said out loud

The @match fix is a pattern inspection, not a browser run. I read the two patterns against Tampermonkey match rules. I never loaded the script in a real browser.

My Node harness covers the script body: a query page moves to StartPage, and a page with no query keeps its address. It does not prove Tampermonkey behaviour, install behaviour, or anything on a live DuckDuckGo page.
